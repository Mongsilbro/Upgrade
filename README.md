# Upgrade

매일 하나씩, GitHub 오픈소스에서 쓸 만한 기법을 골라 Claude 스킬로 옮겨 담는 저장소입니다.

- 스킬: [`.claude/skills/`](.claude/skills)
- 채택 기록: [`UPGRADES.md`](UPGRADES.md)
- 채택 절차와 검증 기준: [`CLAUDE.md`](CLAUDE.md)

## 다른 채팅에서 쓰는 법

| 어디서 | 방법 |
|--------|------|
| 이 저장소를 연결한 Claude Code 세션 | 자동으로 로드됩니다. |
| 다른 프로젝트 | 스킬 폴더를 그 프로젝트의 `.claude/skills/`에 복사합니다. |
| 내 컴퓨터의 모든 Claude Code 세션 | 스킬 폴더를 `~/.claude/skills/`에 복사합니다. |
| claude.ai 채팅 | 스킬 폴더를 zip으로 묶어 설정 → 기능 → 스킬에서 업로드합니다. |
